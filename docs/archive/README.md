# 过程归档

这里保存开发过程中的核查、计划和验收记录，供需要追溯时查阅。它们记录的是当时的状态，部分内容（如“学习待办”页面、固定 3/7/14 天复习间隔、14 段演示会话）已被后来的版本取代，当前设计以 [项目报告](../PROJECT_REPORT.md) 为准。

- `HW2_REQUIREMENTS_REVIEW.md` 与两份 `HW2_*EVIDENCE.json`：第一次对照作业要求的核查及其基线证据。
- `IMPLEMENTATION_VERIFICATION.md`：针对上述核查的整改验收。
- `USABILITY_PLAN.md`：七项可用性增强的实施计划，结果见 [USABILITY_FEATURES.md](../USABILITY_FEATURES.md)。
