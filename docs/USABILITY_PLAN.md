# StudyVault 可用性增强实施计划

本计划已按下述范围实施；完成情况、接口、截图和验收见 [USABILITY_FEATURES.md](USABILITY_FEATURES.md)。

## 目标与交付

落实本轮提出的全部七项功能，沿用本地 FastAPI/SQLite 和现有页面，补齐 API、自动化测试、真实浏览器截图及附加功能文档。现有历史快照不改写；新增数据表通过启动时的附加 DDL 创建。

## 实施顺序与确定的行为

1. **复习先回忆再揭晓**：初始只显示问题；点击或空格揭晓后才出现评分按钮；键盘 1/2 分别答错/答对，输入表单时不截获快捷键。
2. **学习待办清单**：集中显示用户写入的疑问、纠错、重点/待练习批注，支持类型/完成状态筛选、分页、解决/重新打开和跳转原消息；不将历史自动标注直接当作用户待办。
3. **卡片管理**：查看所有卡片，修改问题/答案、暂停/恢复及调整下次到期日期；保留卡片 ID、连续答对次数和逐次日志。
4. **完整备份与恢复**：下载完整 SQLite 快照；上传备份先校验并预览数量，用户确认后恢复；恢复前自动保存当前库，提供下载入口。用 SQLite backup API 和进程内数据库锁保证一致性；拒绝运行中导入任务期间恢复。
5. **排版阅读**：本地提供 Markdown、数学公式和代码块渲染及复制按钮；前端依赖随项目提供，运行时不从 CDN 加载；原始正文仍按原文保存。
6. **收藏与阅读进度**：收藏筛选、最近阅读；保存筛选条件、页码、会话和消息位置，刷新后可继续阅读。持久状态写入 SQLite，纳入完整备份。
7. **导入预览与进度**：页面上传现有支持的 Agent JSON/JSONL，自动识别或手动选择平台，预览新增/重复/异常并选择入库；后台逐文件处理，显示计数、失败原因，可停止后续文件。快照 CLI 恢复和原有扫描入口保持可用。

## 接口与存储

- 新增待办查询/完成状态接口、卡片列表/编辑接口、收藏/阅读进度/界面偏好接口。
- 新增完整库备份下载、恢复预览和确认接口；恢复确认仅接受本次已校验的备份令牌。
- 新增上传预览、启动导入、任务进度及取消接口；任务/上传令牌绑定当前数据库和用户，未确认预览不写学习数据。
- 复用 `annotation.is_resolved` 与 `review_card.status`；新增会话阅读状态和用户偏好表；此前已有的消息、批注、日志和整理记录保留。
- 恢复前备份单独保存在被 Git 忽略的 `backups/`；临时上传文件有大小和数量上限，并到期清理。

## 验收标准

- 原 24 项测试继续通过；新增测试覆盖所有者隔离、校验失败无写入、卡片编辑不重置、待办解决/重开、收藏与进度持久、完整备份往返恢复及上传任务状态。
- 真实 Edge 走通七项功能；答案揭晓前不可评分；复制代码和公式渲染可见；刷新恢复阅读位置。
- 上传预览正确区分新增、重复和失败；导入结果与实际 SQL 计数一致；进度与取消不伪造已处理数据。
- 完整备份还原后批注、手动整理、复习日志、收藏和偏好均一致；恢复前自动备份可以下载，损坏备份不能影响现有库。
- 更新运行说明、`ADDITIONAL_FEATURES.md` 和独立实施证据；截图注明使用的受控样例数据。
